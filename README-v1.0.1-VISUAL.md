# ShipCheck Studio v1.0.1 — 问题工作台截图修复版

该版本在 v1.0.0 本地 Lighthouse 版本基础上，仅修复视觉工作台截图证据读取与提示问题，不改变统一扫描、SEO/GEO、Accessibility、Lighthouse 本地运行器架构。

## 重要变化

- 原版工作台读取 `scan.visual.after`，但扫描流程仅在 `scan.visual` 保留统计元数据，截图放在 `chrome.storage.local['shipcheck.baselines']` 中。已修复工作台从基线库按网页 URL 和扫描时间读取截图的逻辑。
- 当前视口缩略图现在额外记录原始 `window.innerWidth`，问题标记可以按正确宽度定位；历史缩略图如果缺少宽度，仍能预览但不会绘制坐标不可靠的标记。
- 不会用旧的截图冒充新扫描；截图失败、设备未捕获、截图版本不匹配等情况均给出明确理由。
- Mobile/Tablet/Desktop 需要在插件设置主动开启精确多视口截图并授权 `debugger`，否则只显示当前窗口的可见区域截图。

## 安装

1. 推荐先备份原扩展目录，将新版 `shipcheck-ai/` 的内容覆盖到原来 Chrome 已加载的同一路径，然后在 `chrome://extensions` 点击该扩展的「重新加载」，以保持扩展 ID 与现有本地数据。也可以新加载解压目录，但这通常会产生新扩展 ID，之前的扫描历史和截图基线不会自动迁移。
2. 打开目标网页，在插件设置中开启「扫描时保存截图基线并计算像素差异」（默认开启）。
3. 点击「一键扫描全站」，然后到「项目」→「打开可视化问题工作台」。
4. 工作台已开着时，点击右上「读取最新扫描」。
5. 需要三设备截图时，开启「多视口精确截图」并同意浏览器 `debugger` 权限，然后重新扫描。
